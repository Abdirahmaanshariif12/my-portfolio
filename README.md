# IT Student Portfolio

A one-page portfolio for Abdirahmaan Shariif Elmi Nour, an Information Technology student at Mogadishu University. There is no backend and no database.

## Preview the site

From this folder, install dependencies if you have not already:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

To check the production build:

```bash
npm run build
npm start
```

## Edit your details

Change the text in `src/content/profile.ts`. The profile photo and the three project cards are still placeholders.

To show a profile photo:

1. Save the image in the `public` folder, for example `public/profile.jpg`.
2. In `src/content/profile.ts`, set `photoSrc` to `"/profile.jpg"`.

Skills are marked as learning topics. The three projects are examples, not completed work. Replace them only when you have something you actually made.
